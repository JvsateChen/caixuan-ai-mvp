1. 项目概览

采选AI 是一个跨平台智能比价助手，用户通过自然语言对话搜索商品，系统自动在淘宝、京东、拼多多三大平台间进行实时比价，并提供价格趋势分析、价格预警、采购管理等功能。

核心功能

  • AI 对话比价 — 自然语言输入商品需求，AI 解析意图并返回跨平台比价结果
  • 三平台实时比价 — 淘宝/京东/拼多多同款商品价格对比，支持排序
  • 商品详情 — 30 天价格走势图、三平台价格对比表、价格预警设置
  • 价格预警 — 设定目标价，到价自动推送通知（站内/微信/短信）
  • 个人看板 — 监控目标、价格快照、采购记录、周报复盘
  • 企业采购 — 采购数据看板、供应商对比、支出分析、订单管理
  • 用户中心 — 比价历史、收藏夹、预警管理、个人信息
  • 登录注册 — 手机号+验证码登录、微信扫码、第三方登录

目标用户

  • C端消费者：个人购物比价、价格监控
  • B端企业用户：采购数据分析、供应商管理

4. 数据模型

4.1 商品 (Product)

{
  id: string          // "P001"
  name: string        // "Apple iPhone 15 Pro 256GB 钛金属"
  brand: string       // "Apple"
  spec: string        // "256GB / 钛金属原色"
  category: string    // "3C数码" | "美妆护肤" | "日用百货"
  image: string       // "phone" | "cosmetic" | "headphone" | "appliance"
  platforms: Platform[]  // 三平台价格数据
  targetPrice: number    // 用户目标价
  lowest: number          // 当前最优价
  sparkline: number[]     // 30天价格数组(30个点)
}

4.2 平台价格 (Platform)

{
  name: string       // "拼多多" | "京东" | "淘宝"
  price: number      // 当前价格
  prevPrice: number  // 昨日价格
  trend: string      // "down" | "up" | "flat"
  delta: number      // 价格变动(负数=降, 正数=升, 0=持平)
  url: string        // 购买链接
}

4.3 监控目标 (MonitoringTarget)

{
  id: string            // "M01"
  productId: string     // 关联商品ID
  productName: string
  targetPrice: number
  currentPrice: number
  platform: string
  status: string        // "achieved" | "monitoring"
  createdAt: string     // "2026-08-15"
  trend: string         // "down" | "up" | "flat"
}

4.4 价格快照 (PriceSnapshot)

{
  id: string
  productId: string
  productName: string
  platform: string
  price: number
  prevPrice: number
  change: number       // 变动金额
  trend: string
  snapshotAt: string   // "2026-09-09 08:00"
}

4.5 采购记录 (PurchaseRecord)

{
  id: string           // "PR01"
  productId: string
  productName: string
  platform: string
  price: number        // 单价
  qty: number          // 数量
  total: number        // 总价
  status: string       // "completed" | "pending"
  orderDate: string
  commission: number   // 佣金
}

4.6 周报复盘 (WeeklyReview)

{
  weekRange: string        // "2026-09-02 ~ 2026-09-08"
  totalSavings: number     // 累计节省
  itemsCompared: number    // 比价次数
  ordersPlaced: number     // 下单数
  commissionEarned: number // 佣金收入
  bestDeals: BestDeal[]
  trend: string            // "up" | "down"
  savingsChange: number   // 节省变化百分比
}

// BestDeal
{
  productId: string
  name: string
  platform: string
  saved: number         // 节省金额
  originalPrice: number
  finalPrice: number
}

4.7 企业采购订单 (EnterpriseOrder)

{
  id: string          // "EO-2026-001"
  title: string       // 订单标题
  supplier: string    // 供应商
  items: number       // 商品数
  total: number       // 总金额
  status: string      // "approved" | "pending" | "completed"
  date: string
  buyer: string       // 采购人
}

4.8 企业采购统计 (EnterpriseStats)

{
  monthlySpend: number
  monthlyOrders: number
  avgDiscount: number     // 平均折扣%
  suppliers: number       // 供应商数
  spendByCategory: CategorySpend[]
  supplierCompare: SupplierCompare[]

// CategorySpend
{ name: string, value: number, pct: number }

// SupplierCompare
{ name: string, orders: number, total: number, avgTime: number, rating: number }

4.9 价格预警 (PriceAlert)

{
  id: string            // "M01"
  productId: string
  name: string
  targetPrice: number
  currentPrice: number

5. API 接口规格

实现说明
原型中所有 API 在 app.js 的 API 对象中以 Mock 方式模拟，包含 500-1100ms 随机延迟和 8%-15% 随机失败率（用于测试骨架屏和错误重试）。工程实现时需替换为真实后端 API。
方法路径参数返回说明
POST/api/ai/chat{ query: string }{ query, parsed, results: Product[], total }AI对话比价
GET/api/products—Product[]商品列表
GET/api/products/:ididProduct商品详情
GET/api/products/:id/price-historyidPriceHistory30天价格历史
GET/api/monitoring-targets—MonitoringTarget[]监控目标列表
GET/api/price-snapshots—PriceSnapshot[]价格快照列表
GET/api/purchase-records—PurchaseRecord[]采购记录列表
GET/api/weekly-review—WeeklyReview周报复盘数据
GET/api/enterprise/orders—EnterpriseOrder[]企业采购订单
GET/api/enterprise/stats—EnterpriseStats企业采购统计
POST/api/price-alerts{ productId, targetPrice }{ success, id }设置价格预警

6. 页面功能规格

6.1 首页 (index.html)

页面结构

  1. 共享 Topbar — Logo + 导航(AI比价/我的看板/企业采购) + 通知铃铛 + 头像
  2. 精简 Hero — 标题"用对话找到全网好价" + 副标题
  3. AI 对话卡片 — 消息区(可滚动) + 底部输入栏
  4. 热门比价 — 3个商品卡片网格

交互细节

  • AI对话流程: 用户输入 → 显示用户气泡 → AI解析中间态(3步流式文本: "正在识别搜索意图..." → "关键词解析..." → "正在匹配三平台...") → 打字动画 → AI回复(含迷你比价卡片)
  • 快捷搜索: 4个快捷标签(iPhone 15 Pro比价/兰蔻小黑瓶/Sony降噪耳机/戴森吸尘器), 点击即发送
  • AI回复内容: 匹配商品数 + 每个商品的3平台迷你比价卡片(平台名/价格/趋势) + "查看完整比价"按钮(跳转compare.html)
  • 热门商品卡片: 商品图 + 名称 + 最优价 + 趋势Badge + sparkline迷你折线图, 点击跳转detail.html
  • 通知铃铛: 点击Toast提示"您有1条价格预警提醒"

骨架屏

  • 热门商品: 3个骨架卡片(图片区+标题+价格+sparkline)
  • AI对话: 解析中间态文本 + 打字动画

错误处理

  • AI对话失败: Toast错误(含重试按钮)
  • 热门商品加载失败: Toast错误(含重试按钮)

6.2 比价结果页 (compare.html)

页面结构

  1. 共享 Topbar
  2. 页面头部 — 返回按钮 + 标题"比价结果" + 副标题(搜索关键词)
  3. 搜索栏 — 搜索图标按钮 + 输入框 + 筛选按钮
  4. 商品摘要卡片 — 商品图 + 分类/品牌/规格标签 + 名称 + 当前最优价 + "设置价格预警"按钮
  5. 三平台比价卡片 — 排序按钮组(价格升序/降序/趋势优先) + 3个平台卡片
  6. 价格统计 — 4个统计卡片(当前最优价/30天最优价/30天均价/相比最高价节省)
  7. 相关推荐 — 最多6个商品卡片

交互细节

  • URL参数: ?id=商品ID&q=搜索词 — id默认P001
  • 搜索栏: 搜索图标可点击(按钮元素), 输入框回车也可搜索, 跳转compare.html?id=&q=
  • 排序: 点击排序按钮即时重排平台卡片(不重新请求API)
  • 最优价卡片: 边框2px绿色, 顶部带"最优价"Badge; 若达到目标价额外显示彩虹Badge"目标达成"+彩虹流光动画
  • 原价/折扣: 有折扣时显示删除线原价+"-X%"绿色Badge; 涨价时显示原价+"+金额"红色Badge
  • 购买按钮: 点击Toast提示"正在跳转至XX平台..."(实际应跳转外链)
  • 预警按钮: 点击跳转detail.html?id=
  • 更新时间: 显示"更新于 M/D HH:MM"
  • 相关推荐: 排除当前商品, 每个卡片带推荐理由Badge(同价位更优/你可能关注/更划算选择/同类热销/品牌推荐/趋势下降中)

    • 骨架屏

    • 商品摘要: 左侧骨架图片 + 右侧骨架文本行
    • 比价卡片: 3个骨架卡片(圆形图标+价格+趋势+块状区域+按钮)
    • 统计卡片: 4个骨架统计卡
    • 相关推荐: 3个骨架商品卡

    5. 30天价格走势图 — SVG折线图(三平台) + 图例 + 统计卡片(最优价/最高价/均价/节省)
    6. 三平台价格对比表 — 表格(平台/当前价/昨日价/变动/趋势/去购买按钮)
    7. 价格预警表单 — 目标价输入 + 推送渠道(站内必选/微信/短信) + 提交按钮

    交互细节

    • URL参数: ?id=商品ID

    • 价格走势图: 纯SVG实现, 三平台不同颜色折线, Y轴价格刻度, X轴日期(每5天显示), 末端圆点
    • 预警表单: 目标价默认填入当前最优价; 提交时按钮显示spinner+"提交中..."; 成功Toast显示目标价+通知渠道; 失败Toast含重试
    • 面包屑"比价结果": 点击跳转compare.html?id=(带productId)
    • "返回比价"链接: 同样带productId跳转

      • 骨架屏

      • 商品头部: 骨架图片 + 骨架Badge + 骨架标题 + 骨架价格 + 3个骨架按钮
      • 价格图: 骨架标题 + 骨架块状区域(280px)
      • 对比表: 骨架行(3行, 每行: 圆形+文本+文本)
      • 相关推荐: 3个骨架商品卡

      6.4 我的看板 (dashboard.html)

      页面结构

      1. 共享 Topbar
      2. 侧边栏+内容区布局
      3. 页面头部 — 标题 + 副标题 + "导出报告"按钮
      4. 概览统计 — 4个统计卡片(累计节省/监控商品数/采购订单/佣金收入)
      5. Tab切换 — 监控目标/价格快照/采购记录/周报复盘
      6. 侧边栏 — 数据看板(4个Tab) + 工具(预警通知/我的收藏/个人中心, 跳转profile.html?tab=)

      Tab1: 监控目标

      • 表格列: 商品名称/目标价/当前价/平台/差距/状态/操作
      • 达标行: 彩虹流光背景动画
      • 差距: 正数红色(差多少), 负数绿色(已低于目标)
      • 状态Badge: 已达标(绿色✓) / 监控中(黄色时钟)
      • 操作: "查看详情"跳转detail.html?id=

      Tab2: 价格快照

      • 表格列: 商品名称/平台/当前价格/昨日价格/变动/趋势/快照时间
      • 变动: +金额(红) / -金额(绿) / 持平(黄)

      Tab3: 采购记录

      • 表格列: 订单号/商品名称/平台/单价/数量/总价/佣金/状态/日期

document.getElementById('icon').innerHTML = Icon.search(20);

  el.innerHTML = Icon[el.dataset.i](parseInt(el.dataset.s || '20'));
});

// 3. data-icon属性 (dashboard/admin使用)
<span data-icon="download" data-size="16"></span>

});

      9.5 注意事项

      • XSS防护: 原型中使用 escapeHtml() 函数转义用户输入, 工程实现时使用框架内置转义
      • 价格格式化: 使用 ¥ + toLocaleString('zh-CN') 格式, 注意整数无小数
      • URL参数: 所有跨页跳转需正确传递 id 和 q 参数, 使用 encodeURIComponent
      • 骨架屏: 每个异步数据区域都必须有骨架屏, 不能直接显示空白
      • 错误重试: Toast错误提示必须包含可点击的"重试"按钮
      • 平台颜色: 淘宝#ff6a00, 京东#1677ff, 拼多多#e02130, 全局统一
      • 图标: 全部内联SVG, 不使用emoji, 不依赖外部图标库
      • 商品图片: 使用Unsplash占位图, 工程实现替换为CDN商品图
      • 动画性能: 彩虹流光使用CSS animation transform/opacity, 避免重排
      • 表格响应式: 使用 overflow-x:auto 而非隐藏列
